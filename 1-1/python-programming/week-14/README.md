# 🧱 Pygame 벽돌깨기

> 공과 패들의 움직임, 벽돌 충돌, 점수와 게임 상태를 직접 제어해 완성한 Python Programming 과목의 최종 프로젝트입니다.

Pygame의 게임 루프 안에서 사용자 입력을 처리하고 객체의 위치를 갱신한 뒤, 충돌 결과와 현재 상태를 화면에 그리는 전체 흐름을 구현했습니다. 개발 과정에는 생성형 AI를 보조 도구로 활용하고 생성된 코드를 직접 검토·수정했습니다.

## 프로젝트 개요

| 항목 | 내용 |
| :-- | :-- |
| **과목** | Python Programming |
| **주차** | 14주차 최종 프로젝트 |
| **장르** | Brick Breaker |
| **라이브러리** | Pygame |
| **화면 크기** | 800 × 600 |
| **초기 목숨** | 3 |

## 게임 방법

- 왼쪽·오른쪽 방향키로 패들을 움직입니다.
- 공이 화면 아래로 떨어지지 않도록 패들로 받아 냅니다.
- 일반 벽돌은 `10점`, 금색 보너스 벽돌은 `20점`을 얻습니다.
- 공을 놓치면 목숨이 하나 줄고 공과 패들의 위치가 초기화됩니다.
- 모든 벽돌을 제거하면 승리하며, 목숨을 모두 사용하면 게임이 종료됩니다.

## 주요 구현

### 패들 이동

매 프레임 키보드 상태를 확인해 패들의 x좌표를 변경합니다. 패들이 화면 밖으로 나가지 않도록 좌우 경계에서 위치를 제한했습니다.

### 공의 반사

공이 화면의 좌우·위쪽 벽에 닿으면 이동 방향을 반전합니다. 패들과 충돌할 때는 맞은 위치를 이용해 좌우 이동량을 조정하므로 항상 같은 각도로만 튀지 않습니다.

### 벽돌 충돌과 점수

공과 벽돌을 `pygame.Rect.colliderect()`로 비교합니다. 한 프레임에서 충돌한 벽돌을 찾아 제거하고, 벽돌 종류에 따라 점수를 더한 뒤 공의 세로 방향을 반전합니다.

### 게임 상태

화면 상단에 점수, 남은 목숨과 벽돌 수를 표시합니다. 모든 벽돌을 제거한 경우 `YOU WIN!`, 목숨이 0이 된 경우 `GAME OVER` 메시지를 보여 줍니다.

## 실행 방법

Python 3 환경에서 Pygame을 설치한 뒤 실행합니다.

```bash
pip install pygame
python brick-breaker.py
```

그래픽 창과 키보드 입력을 사용하는 프로그램이므로 데스크톱 환경이 필요합니다.
