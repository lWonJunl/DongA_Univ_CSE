## 🔍 Representative Approaches

### 조건의 순서 정하기

주사위 세 개의 상금을 계산할 때는 세 값이 모두 같은 경우, 두 값만 같은 경우, 모두 다른 경우를 순서대로 분리했습니다. 더 구체적인 조건부터 검사해야 중복된 경우를 정확히 처리할 수 있다는 점을 확인했습니다.

### 시간을 하나의 단위로 계산하기

오븐 시계 문제에서는 현재 시각과 조리 시간을 분 단위로 계산한 뒤 시와 분으로 다시 나눴습니다. 하루를 넘어가는 경우에는 24시간 범위로 값을 조정했습니다.

### 행과 열을 따로 제어하기

별 찍기 문제에서는 바깥쪽 반복문이 행을, 안쪽 반복문이 공백과 별의 개수를 담당하도록 구성했습니다. 같은 중첩 반복문이라도 출력 순서에 따라 왼쪽 정렬과 오른쪽 정렬이 달라지는 것을 비교했습니다.

### 문자열 조건 검사하기

비밀번호 문제에서는 정수 배열이 아닌 문자 배열로 입력을 받고 `strlen`을 사용해 허용 길이인지 판정했습니다. 숫자로 보이는 입력도 계산 대상이 아니라면 문자열로 처리할 수 있음을 학습했습니다.

## ▶️ Compile & Run

GCC가 설치된 환경에서는 다음과 같이 원하는 풀이를 컴파일합니다.

```bash
gcc 10869-arithmetic-operations.c -o solution
./solution
```

Windows PowerShell에서는 생성된 실행 파일을 다음과 같이 실행합니다.

```powershell
.\solution.exe
```

BOJ에 제출할 때는 문제에서 요구한 값만 출력해야 하므로 입력 안내 문구나 추가 설명을 프로그램 출력에 넣지 않습니다.
