# 1주차 2차시

> 수업 날짜: `2026-09-02`

## 배운 명령어

### 1. `sudo`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `sudo 명령` |
| 기능 | 일시적으로 슈퍼유저(`root`) 권한으로 원하는 명령을 실행한다. |
| 옵션 | 없음 |
| 인자 | 관리자 권한으로 실행할 명령 |

#### 사용 예시

```bash
sudo apt install gcc
```

---

### 2. `su`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `su [사용자명]` |
| 기능 | 사용자명을 주지 않으면 `root`로 전환하고, 사용자명을 주면 해당 사용자로 전환한다. |
| 옵션 | 없음 |
| 인자 | `사용자명`: 전환할 계정. 생략하면 `root` 사용자로 전환 |

#### 사용 예시

```bash
su
su 사용자명
```

---

### 명령어 표기 형식

- `명령어 인자`: 해당 인자를 입력해야 하는 형식
- `명령어 [인자]`: 대괄호 안의 인자는 선택적으로 입력하는 형식
- 대괄호(`[ ]`)는 표기일 뿐, 실제 명령어 입력에는 포함하지 않는다.
- Ubuntu에서는 일반적으로 `root`로 직접 로그인하는 것보다 `sudo` 사용을 권장한다.
