# 1주차 2차시

> 수업 날짜: `2026-09-02`

## 배운 명령어

### 1. `sudo`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `sudo 명령` |
| 기능 | 일시적으로 `root` 권한으로 명령 실행 |
| 옵션·인자 | 별도 옵션·인자 정리 |

#### 사용 예시

```bash
sudo 명령
```

---

### 2. `su`

| 항목 | 내용 |
| --- | --- |
| 명령어 | `su [사용자명]` |
| 기능 | 다른 사용자로 전환 |
| 옵션·인자 | `사용자명`을 생략하면 기본적으로 `root` 사용자로 전환 |

#### 사용 예시

```bash
su 사용자명
su
```

## 명령어 표기 형식 메모

- `명령어 인자`: 해당 인자를 입력해야 하는 형식
- `명령어 [인자]`: 대괄호 안의 인자는 선택적으로 입력하는 형식
- 대괄호(`[ ]`)는 표기일 뿐, 실제 명령어 입력에는 포함하지 않는다.
